# Machine Learning Models

This repository contains various machine learning models and their implementations. Below is a brief description of each folder in the root directory:

## [00_Transformer](./00_Transformer)
This folder contains training code for a sample transformer model using Hugging Face. It provides an overview of the self-attention mechanism and its implementation.


## [01_Stable_Diffusion](./01_Stable_Diffusion)
This folder contains training code for stable diffusion model. It provides an overview of the encoder, decoder, how to add noise, and other related concepts.

## [02_Vision_Model](./02_Vision_Model)
This folder contains code for tokenizer and vision models such as SigLip, Gemma and PaliGemma. 

## [03_Llama](./03_Llama)
This folder contains inference pipleine for Llama model. 

## [04_RAG](./04_RAG)
This folder contains training code for a sample transformer model using Hugging Face. It provides an overview of the self-attention mechanism and its implementation.

## [05_Quantization](./05_Quantization)
This folder contains code for RAG fundamentals, PDF parser using multimodal models and how to locally deploy chat bots.
